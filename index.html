Support_Matrix

Batch Processing Protocol (Mass Orders)

Navigate to the Terminal matrix. Engage a node (product) to initialize it in the cart. Within the payload panel, override the numerical input directly (e.g., "50") to bypass manual recursion cycles (repeated clicking).[cite: 1]

VIP Merit & Tier Upgrades

Entities automatically accumulate 1 metric (point) for every ₱100 transferred. During execution, points convert to direct discounts (1 pt = ₱1). The mainframe continually monitors lifetime volume to auto-promote users through VIP classifications.[cite: 1]

Manual Profile Overrides

Access the VIP Network tab. Locate the target entity and engage EDIT. This grants root access to modify their Designation, Comms, forcefully lock their VIP Tier (bypassing the auto-calculator), and manually alter their merit points.[cite: 1]

Promotional Pricing Protocol

In the Database Inventory, click EDIT on an item. Inject a discounted metric into the "Promo Override" field. The system instantly broadcasts a SALE badge to the Terminal and mainframes. Nullify (clear) the field to restore base metrics.[cite: 1]

Analytics Telemetry (Dashboard Chart)

The Dashboard cross-references current Order Logs to visualize historical telemetry. Selecting Day, Week, or Month cycles compares the trailing 7 periods and calculates exact differential percentages to gauge network velocity in real-time.[cite: 1]

System Reset & Mockup Data Injection

For client presentations, navigate to System Config. Engaging the "INJECT MOCKUP DATA" protocol will attempt to fetch 'adminmockupdata.txt' from the root directory to instantly populate the grid with test entities and transactions.

Data Extraction (System Backups)

In the System Config panel, under "Unified Data Core", clicking "EXTRACT PAYLOAD" compiles your entire local array (Inventory, Logs, VIPs) into a secure, timestamped JSON text file downloaded directly to your hard drive.[cite: 1]

Restoring System Data

To restore a previously extracted payload, go to System Config and select "INJECT BACKUP". Choose the downloaded Nexus POS text file. The system will parse and overwrite the current state with the backup metrics.[cite: 1]

Handling Walk-in vs Registered Entities

In the Terminal Matrix checkout panel, the top dropdown defaults to Walk-in (Ghost User). If left as Walk-in, you can optionally type a name to quickly log the user. If you select a registered VIP from the dropdown, their current merit points will instantly become available for deployment.[cite: 1]

Editing & Purging Existing Nodes (Inventory)

Navigate to Database Inventory. You can completely overwrite a node's pricing, stock availability, or SKU by clicking EDIT. To permanently wipe the node from the system matrix, click DEL.[cite: 1]

Viewing Entity Telemetry (Customer Ledgers)

In the VIP Network tab, clicking "INSPECT" on a user opens their detailed profile. This includes a chronological Ledger Telemetry table tracking exactly when merit points were earned, redeemed, or manually injected/purged by an Admin.[cite: 1]

Require Engineering Support?

If terminal anomalies persist or feature injections are desired, establish comms with the development nexus.[cite: 1]
