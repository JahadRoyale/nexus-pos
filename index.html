System Architecture & Help Center

Nexus Offline POS – Next-Gen Local Point of Sale

Nexus POS is a sleek, high-tech Point of Sale system designed specifically for local retail and service businesses. Built with a premium, modern aesthetic, it provides robust inventory and transaction management entirely offline. No internet connection, no server outages, and no monthly cloud hosting fees—just blazing-fast, secure local performance.

Client Guide

1. Getting Started & Dashboard

The dashboard provides a real-time overview of today's performance. It works completely offline, meaning you don't need internet to process sales.

Data Backup: Because data lives on your device, use the Export buttons on the Dashboard weekly to save backups to a USB drive.

2. Processing an Order

  • Go to POS / Terminal.
  • Click items in the grid to add them to the cart.
  • Select an existing customer from the dropdown to award them points, or leave as Walk-in.
  • Add any standard manual discounts or taxes.
  • Click Complete Transaction.

3. The Customer Retention / VIP Program

Nexus POS automatically tracks loyal customers. You do not need to calculate points or upgrade tiers manually.

  • Earning: Customers automatically earn 1 point for every ₱100 spent in a completed order.
  • Redeeming: 1 Point = ₱1. During checkout, select the customer and type the points they wish to redeem. It will instantly deduct from the total.
  • VIP Tiers: As lifetime spending increases, tiers auto-upgrade: Bronze (₱5k), Silver (₱10k), Gold (₱50k), Platinum (₱100k).

4. Managing Inventory & Customers

Inventory: Add products via the Inventory tab. Ensure SKUs (barcodes/identifiers) are unique. The POS terminal prevents selling depleted stock.

Customers: Customers are automatically generated if you type a new name/phone in the Walk-in section during checkout. You can also manually add them in the Customers tab.
