Batch Processing Protocol (Mass Orders)

Navigate to the Terminal matrix. Engage a product to initialize in the cart. Within the cart panel, input specific numerical values directly into the quantity field (e.g., "50") to bypass manual recursive clicking.

VIP Merit & Tier Upgrades

Entities automatically accumulate 1 metric for every ₱100 transferred. During execution, points convert to direct discounts (1 pt = ₱1). The mainframe monitors lifetime volume to auto-promote through VIP classifications.

Override: Administrators can recalibrate spending algorithms via the Settings module.

Manual Profile Overrides

Access the VIP Network. Locate the target entity and engage Edit. This grants root access to modify Designation, Comms, forcefully lock VIP Tier (bypassing auto-calc), and manually alter merit points.

Promotional Pricing

In the Database Inventory, edit an item. Inject a discounted metric into the "Promo Price" field. The system instantly broadcasts a SALE badge to the Terminal and mainframes. Nullify the field to restore base metrics.

Analytics Telemetry

The Dashboard cross-references current Order Logs to visualize historical telemetry. Selecting Day, Week, or Month cycles compares the trailing 7 periods, calculating exact differential percentages to gauge network velocity.
